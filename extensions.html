Chromium desktop family

One Manifest V3 build targets Chrome, Edge, Brave, Opera, Vivaldi, and Chromium. Development installation may be restricted by your organization.

Download Chromium development ZIP
  1. Extract the ZIP into a folder and keep that folder.
  2. Open your browser’s extensions manager: chrome://extensions, edge://extensions, brave://extensions, opera://extensions, or vivaldi://extensions.
  3. Enable Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.
  4. Pin Music Platform Companion to the toolbar and open it. Review the browser’s prompts before approving.

Firefox desktop

Firefox 142 or later. Unsigned development build for temporary testing; removed when Firefox restarts. A signed release is still required for normal persistent installation.

Download Firefox development ZIP
  1. Extract the ZIP.
  2. Open about:debugging#/runtime/this-firefox.
  3. Choose Load Temporary Add-on and select manifest.json in the extracted folder.
  4. Open the companion from Firefox’s extensions menu.

Safari on macOS

Conversion source only. This ZIP cannot be installed directly in Safari. A Mac with Xcode is required to package and test it; distribution requires Apple signing and the relevant developer account.

Download Safari conversion source

After extraction, use Apple’s Safari Web Extension tooling in Xcode to convert the folder, review compatibility warnings, and build the containing app. Enable the resulting extension in Safari settings.

Phones and tablets

This release targets desktop installation. Mobile extension availability depends on browser and platform; no mobile build is offered yet. The Music Platform mobile and tablet interfaces work directly, without an extension.

Privacy and permissions

The companion requests no extension permissions or website access. It contains no background worker, content scripts, trackers, or remote scripts, and does not inspect tabs, recordings, or browser history. It only opens fixed Music Platform links when clicked.

The website receives normal web requests when opened. Microphone permission belongs to the Recording tool in the website and is requested only after Start recording. The companion does not bypass that permission.

Source and build instructions are in the repository’s extensions directory. Store listings and automatic updates are not available for these development builds.
